# The model reads a distant first-hop binding swap

The [frozen first-hop test](firsthop_swap_patch_prereg.md) moved the counterfactual from the second-hop destination clauses to the earlier **route→link clauses** of the same eight constructed two-hop domains. The complete second-hop text, including the destination noun immediately before the measured period, is identical across each world pair. The committed [exact-text grid](../prompts/firsthop_swap_v1.json) and [token audit](../results/firsthop_swap_v1_token_audit.json) show 64/64 world pairs have equal prompt token length, equal period token index and ID, and identical second-hop token IDs. This is a conditional follow-up on eight previously successful story domains, not a fresh corpus replication.

Model: NDIF's pinned `google/gemma-2-9b-it`, local tokenizer snapshot `11c9b309abf73637e4b6f9a3fa1e92e615547819`. NDIF exposes no weight revision hash. The [committed score report](../results/firsthop_swap_behavior_v1_summary.json) contains all 128 two-candidate score pairs, margins, domain and factor values, exact null, code and grid digests, and all five eligibility gates. The ignored local cache retains the individual, fingerprinted jobs.

The registered behavioral eligibility gate **passes**: both world×goal margin contrasts exceed +0.25 nat in **29/32** `(domain, name assignment, plan order)` quartets. The eight-domain relabel exact test has **p=1/256**, its floor. All four fact-order quadrants pass at **8/8, 7/8, 7/8 and 7/8**; the two name halves are 13/16 and 16/16, and the two plan-order halves are 14/16 and 15/16. I recomputed the 29 joint quartets directly from the cached candidate scores, separately from the report's analyzer.

This is a **relative preference** result. The model makes the correct top-name choice in **109/128 cells**, but all four cells are correct in only **19/32 quartets**. Here “strict” means a margin strictly above zero for the correct name, with no ±0.1-nat cutoff; it should not be compared numerically to the late-reveal study's stricter threshold. The other-world winner is already top ranked in 19/128 target prompts, a pre-scoring count needed for the causal test's choice-redirection screen.

The positive relative result shows that the model uses information from the earlier route–link assignments, despite the identical later destination sentences. It does not show where that information sits in activations or whether a single story-token state can transmit it. The preregistered causal patch is now eligible and remains a separate decision, with matched plan-order and first-hop-clause-order controls.

# Can a story-token state transmit a distant route–link swap?

**Frozen before any new model score or activation.** This is a follow-up to the [single-period story patch](story_fact_token_patch_result.md). That patch changed the final second-hop destination nouns. Its signed margin effect was mainly confidence compression, and a matched plan-order control was larger. Here the counterfactual changes the **earlier first-hop route–link assignments** while leaving the complete second-hop text and the noun immediately before the patched period identical. This removes the most local lexical route to a positive period-state patch. A success would still be a constructed two-hop binding result, not a trope or coherent story transformation.

## Frozen grid and symbolic answer

Reuse exactly the eight story domains, names, goals, plan and fact-order bits, templates, neutral bridge and question in `research/narrative/prompts/goal_route_cross_v1.json` at its committed digest. Use `google/gemma-2-9b-it` on NDIF and the Gemma tokenizer snapshot `11c9b309abf73637e4b6f9a3fa1e92e615547819`; NDIF does not expose a weight revision hash. The new grid is conditional on these eight domains, which were used in the prior positive behavioral screen.

Use only the **late** telling: setup, one of the two goal sentences, the two name→route plan sentences, the two route→link first-hop sentences, the two link→destination second-hop sentences, the original neutral bridge, then the unchanged question. Cross name assignment, plan-sentence order, world and goal, all binary: eight domains × sixteen cells = **128 prompts**. Within each domain, preserve its frozen two fact-order bits. World 0 has `route[0]→link[0]` and `route[1]→link[1]`; world 1 exchanges **only the link names in those two first-hop sentences**. In both worlds, `link[0]→target` and `link[1]→foil` are fixed. Goal 0 requests target; goal 1 requests foil. The correct plan-A owner has sign `+1` iff `world == goal`; derive that independently by parsing the constructed plan→route→link→destination graph and assert the formula on every cell. Candidates are the same two bare names, sorted alphabetically, one token each.

The world pair must have the same names, goal, plan text, second-hop text, word multiset, length, final 200 characters and exact text suffix from the start of the second-hop facts. There must be one BOS and no candidate-row padding. At the informative **period ending the last second-hop clause**, before the neutral bridge or question, assert equal prompt token counts, equal period indices and period token IDs, and equal token IDs for every token wholly inside the second-hop text through that period. This suffix check is stronger than matching the final noun alone: the two worlds differ only in the earlier route–link binding. A pre-score tokenizer audit with the frozen snapshot found all 64 world pairs matched in prompt length and period index, with identical suffix text and word bag; the committed builder must reassert this on every run.

## Measurement sequence and eligibility

1. Commit the deterministic grid builder, token audit, exact baseline texts and code fingerprints before NDIF scoring. Review the builder's factor order, symbolic winners, and patching diff against the frozen grid before a score is interpreted.
2. Score **all 128 unpatched prompts** in fixed two-candidate jobs with the verified fp32 Gemma softcap, one BOS, zero padding and unchanged batch shape. Cross-check the new scorer against the core on the shortest and longest prompts to 1e-3. For each `(domain,name,plan)` quartet let `m(w,g)=logp(plan-A owner)−logp(plan-B owner)`, `D0=m(0,0)−m(1,0)` and `D1=m(1,1)−m(0,1)`. Count a joint read when both exceed +0.25 nat. The patch result is **ineligible** if fewer than 24/32 quartets read jointly, if either name or plan-order half has fewer than 10/16, if any of the four frozen fact-order quadrants is at or below 4/8, or if the exact eight-domain relabel null gives p>.05. Report strict four-cell correct choices and the number of baseline cells already favouring the other-world winner before causal scoring. If ineligible, publish the behavioral failure and stop before causal scoring.
3. Capture the post-block-24 residual at that period for all **128 new-grid target prompts** and 128 same-world prompts with the first-hop clause order reversed, in the same two-candidate batch shape as scoring. The two candidate rows must be bit-identical there. Each reversed-plan-order state is another target **within these 128 new-grid captures**, including the 64 world-1 targets; do not reuse any state from the earlier destination-swap grid. Re-capture the eight cells with `(name,plan,world,goal)=(0,0,0,0)`, one per domain, to verify deployment drift and source/target state readability. As in the previous period patch, score a no-patch, zero-vector, source-world substitution, same-world reversed-plan-order state, same-world reversed-first-hop-clause-order state, seeded norm-matched Gaussian, and same-period final-block-41 pass-through arm on every prompt. The Gaussian uses `default_rng(20260923 + domain_index*16 + name*8 + plan*4 + goal*2 + world)` before unit normalization and float32 casting. The source state has the other world with the same domain, name, plan order and goal. Both order controls preserve the symbolic correct person and change only presentation; each control vector is norm-matched to the source-world delta. Assert equal prompt length, period index and period token ID for each order-control pair; a pre-score tokenizer audit found all 128 first-hop-order pairs matched. At least one direct residual-reach preflight must test both candidate rows, and a deliberate row-0-only patch must be refused by the armed moved-candidates assertion. Keep the prior deterministic two-rerun policy for bf16-identical scores, with a ≤5% flagged-job ceiling across all nonzero block-24 jobs. Zero and block-41 score changes must be ≤1e-3. Check that the patched period state equals the same-batch source state up to bf16 arithmetic. Cache every job under prompt, grid, model, tokenizer, code, arm and vector fingerprints; reject stale rows, retry queue failures at the same shape.

The single-position scorer may reuse the reviewed line-local trace from `scripts/narrative/story_fact_token_patch.py`, but any new extraction, patching or ranking code requires peer review of the diff under instrument rule 5. Do not edit shared core to run this spike.

**Instrument amendment after unpatched baseline scoring began, before any state capture or patch score:** require the maximum of the eight fixed repeat-state relative L2 errors to be ≤0.02; require every source–target state-difference norm to exceed ten times that maximum times the target residual norm; and require the source-state relative L2 error after the full patch to be ≤0.02. These are readability and patch-reach gates, using the previous same-token run's 0.02 state-comparison bound. A failed gate invalidates a causal reading rather than becoming a patch null. This amendment does not alter the behavioral, causal-effect or control thresholds.

## Frozen causal and reading gates

For target world `w` and goal `g`, define `s=+1` when the other-world winner is the plan-A owner, else `s=−1`. The signed effect for each arm is `s·(m_arm−m_none)`. The primary is the eight-domain mean of the source-world substitution, each domain averaging its 16 cells. Use the exact one-sided 2^8 domain sign-flip null, identity included, and a seeded 10,000-draw domain bootstrap. A **specific margin-bias screen** requires all instrument gates, mean ≥+0.25 nat, p≤.05, bootstrap lower bound >0, at least six positive domains and 96 positive cells, and mean >2× the largest absolute mean of the norm-matched plan-order, first-hop-clause-order and Gaussian controls. Report all controls even if this gate fails. No positive screen is inferred from p alone.

As a **registered secondary binding-over-presentation contrast**, subtract the first-hop-clause-order signed effect from the source-world effect **within each cell**, then take the eight domain means. Both perturbations are same-norm, in-distribution substitutions at the same token; the contrast cancels any common confidence compression more directly than comparing their separate means. Also compute treatment minus plan-order in the same way. For each contrast report its mean, all eight domain values, a one-sided 2^8 domain sign-flip p and a 10,000-draw domain bootstrap interval. Call a secondary contrast positive only if **all instrument gates pass**, its mean is at least +0.10 nat, p≤.05, its bootstrap lower bound is >0 and at least six domain values are positive. A positive secondary with a failed primary is evidence for a relative binding-sensitive component under these controls, **not** a passed specific-edit screen. A negative or mixed clause-order contrast leaves link-position and other presentation codes live. The two controls change different orderings: clause reversal changes which link is mentioned first but preserves which route reaches it; the world swap changes the route–link assignment without changing which route clause is first.

To distinguish redirection from generic margin compression, report the full distribution of absolute name-margin changes and the treatment effect separately where the no-patch margin already favours the source-world winner. The separate **choice-redirection screen** requires the specific margin-bias screen plus at least eight top-name flips *toward* the source-world winner, no more than four flips away, and a positive mean signed effect in the baseline-source-favoured subset if that subset has at least eight cells. If the subset is smaller, label this screen unreadable. The exact thresholds and subset rule are frozen before scoring. A positive relative-score result without the choice screen is a margin effect, not an edited choice.

Report every domain, name, plan, world and goal half, the 64 unordered world-pair contrasts, the source-winner baseline rate, movement flags, zero/pass-through checks, and the result at the preselected period token. The world-pair/domain structure is the unit of inference, not 128 independent prompts. A positive here would show a distant route–link difference can be transmitted from one story-stage state under these controls. It would not prove that the state contains a unique compositional graph code: positional binding, source-text inconsistency after patching, and other token states remain alternatives. A null with all instrument gates passing limits this one-token block-24 intervention, not the availability of the relation elsewhere in the network.
